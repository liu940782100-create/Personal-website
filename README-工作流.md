# 个人网页 · AI 工作流提示词库

> 网页负责"看"和"记"，AI 负责"采集、分析、点评"。
> 日常使用时，把下面对应段落的【提示词】复制发给 AI 助手，产出物最终写回对应的 `data/*.js`。

---

## 目录结构速查

```
个人网页/
├── index.html            门户首页
├── inspiration.html      灵感库
├── projects.html         项目库
├── knowledge.html        个人知识库
├── skills.html           Skills 方法论
├── assets/style.css      全站样式
├── assets/app.js         公共函数
└── data/                 数据文件（唯一事实源）
    ├── inspiration.js    window.DATA_INSPIRATION
    ├── projects.js       window.DATA_PROJECTS
    ├── knowledge.js      window.DATA_KNOWLEDGE
    └── skills.js         window.DATA_SKILLS
```

---

## 1. 灵感采集与叙事分析（写入 data/inspiration.js）

在【平台名，如：知乎】上搜索【领域，如：职场成长】近半年内点赞和评论最高的 5 条内容。对每条输出：标题、作者、链接、点赞/评论数、3 句话内容总结，并拆解叙事手法——开头钩子、叙事结构、情绪曲线设计、以及 3 条我可迁移的技巧。结果按灵感卡片 Schema 整理，写入 data/inspiration.js。

> 抖音/微信公众号有登录墙，追加一句：「如需登录，请在浏览器中引导我完成登录，登录后继续采集。」

## 2. 书籍方法论蒸馏（写入 data/skills.js）

请蒸馏《书名》中的核心方法论。每个方法论输出：名称、一句话核心思想、操作步骤、适用场景、常见误用，并标注它与我知识库中哪些卡片相关（引用 id）。结果按方法论卡片 Schema 写入 data/skills.js。

## 3. 思维点评（对照 data/knowledge.js）

以下是我的一段想法/决策：【粘贴内容】。请对照我的知识库数据（data/knowledge.js），逐条检查：① 我是否忽略了某条知识的适用条件；② 是否无视了"不这么做的后果"；③ 有哪些未经验证的假设；④ 有哪些可引用的方法论。输出：问题清单 + 改进方向，每条注明依据的知识卡片/方法论出处。

> 网页里知识库每张卡片底部的"待点评思维记录"可一键导出成文本，直接粘贴进【粘贴内容】即可。

## 4. 项目设计工作流（五步，写入 data/projects.js）

我要启动项目：【一句话描述】。请按五步工作流推进——
第一步：目标澄清，向我提问直到目标可衡量；
第二步：现状调研，搜索该领域的现有做法与数据；
第三步：方案设计，给出 2 个候选方案及取舍；
第四步：风险评估，列出最大 3 个风险与对策；
第五步：执行计划，拆成两周内的可执行动作。
每步完成后更新 data/projects.js 中该项目的阶段与产出物。

## 5. 知识库批量录入（写入 data/knowledge.js）

以下是我最近的实践心得：【粘贴原始文字】。请拆解成若干知识卡片，每张必须写清：适用条件、具体做法、这样做的后果、不做的后果；无法从原文确定的字段标注"待补充"并列出追问清单，不要编造。结果按知识卡片 Schema 写入 data/knowledge.js。

---

## 维护守则

- **数据唯一事实源**：所有持久数据都在 `data/*.js`，网页内的本地缓存（知识库表单、思维记录）只是暂存，定期用页面的"导出"按钮交回 AI 写回。
- **改数据不改页面**：新增内容一律走 AI 工作流写入数据文件；页面结构不动，避免样式漂移。
- **测试数据可删**：四个数据文件里的示例条目（标题带"示例"字样）开始积累真实内容后可让 AI 清理。
- **离线可用**：全站无外部依赖，双击 index.html 即可；未来要部署上线，静态托管即可。
